41 """Create an issue report.

47 Source:

49 

50 :param summary: name of the report. 

51 :param fields: issue fields to include into the report, e.g. 

52 `["priority", "type", "key", "summary", "assignee", 

53 "status", "updated"]`. A comma-separated string 

54 (`"priority,type,key"`) is accepted too and split into the 

55 JSON array the API wants. 

56 :param format_: export format: "xlsx", "xml" or "csv". 

57 :param query: filter written in the query language. Mutually 

58 exclusive with `filter_` and `filter_id`. 

59 :param filter_: field filters, e.g. 

60 `{"queue": "TREK", "assignee": "empty()"}`. Mutually 

61 exclusive with `query` and `filter_id`. 

62 :param filter_id: id of a saved filter. Mutually exclusive with 

63 `query` and `filter_`. 

64 :param sorts: sorting rules, e.g. 

65 `[ReportSort(order_by="updated", order_asc=False)]`. 

66 :param type_: export type. The only documented value is 

67 "issueFilterExport". 

68 :raises ValueError: if none of `query`, `filter_` and 

69 `filter_id` is given, or if more than one of them is. 

70 :return: the created report. 

71 """ 

72 given = [ 

73 name 

74 for name, value in (
